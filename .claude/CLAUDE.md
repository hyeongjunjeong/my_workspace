# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

# 코딩 스타일
- 변수명은 camelCase 사용
- 함수에는 간단한 JSDoc 주석 추가
- console.log 대신 적절한 로깅 라이브러리 사용

## 언어 및 커뮤니케이션 규칙

- 코드 변경 시 변경 이유를 간단히 설명
- 에러 발생 시 원인과 해결 방법을 함께 제시

- **기본 응답 언어**: 한국어
- **코드 주석**: 한국어로 작성
- **커밋 메시지**: 한국어로 작성
- **문서화**: 한국어로 작성
- **변수명/함수명**: 영어 (코드 표준 준수)

## 자주 쓰는 명령어
- 빌드: npm run build
- 테스트: npm run test
- 린트: npm run lint
